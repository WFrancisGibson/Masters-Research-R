# Masters-Research-R

Research compendium for the masters thesis (R strands).

## Strands
- `analysis/00_claim-simulation/` — `short_tailed_claims.R` simulates the synthetic claims data; writes to `data/raw/claim-simulation/`
- `analysis/01_ODP glm model/` — ODP GLM baseline
- `analysis/02_nn-chain-ladder/` — Track A (Wuthrich 2018) and Track B (Richman & Wuthrich)
- `analysis/03_bccNNodp model/` — bCCNN-ODP model
- `analysis/04_embedded NN odp model/` — embedded-NN ODP model

## Layout
- `R/` — functions only, no top-level code
- `analysis/` — numbered scripts that call functions from `R/`
- `data/raw/claim-simulation/` — simulator outputs (claims, transactions, triangle, covariates); regenerate with the simulation script, never edit by hand
- `data/raw` (never edited) -> `data/interim` -> `data/processed`
- `models/`, `output/` — regenerated by scripts, never saved by hand
- `config.yml` — seeds, hyperparameters, paths (read with `config::get()`)
- `reviews/` — paper-critique .Rmd files
- `thesis/` — chapters and references.bib
- `tests/testthat/` — checks

## Setup
1. Open `Masters-Research-R.Rproj` in RStudio.
2. Run `renv::init()` once, then `renv::snapshot()` after installing packages.
3. Use `here::here()` for all paths and `keras3::set_random_seed()` for NN seeds.
4. `git init` in this folder; keep `renv/library`, `models/` and `.git` out of OneDrive sync.
