::: abstract
This report sets out, formula by formula, the mathematics behind the blended cross-classified neural network that the research code fits to a 20 by 20 annual claims triangle. It starts from the cross-classified over-dispersed Poisson model on which the chain ladder rests, derives its maximum likelihood equations and shows, through the marginal-total property, that the fitted model reproduces the chain-ladder reserve. It then describes the neural network that is wrapped around this model – the frozen embeddings, the skip connection, the three hidden layers with dropout and the exponential output neuron – together with the loss that Keras minimises and its relation to the Poisson deviance.

The gradients of the loss are written out in full. At the prescribed starting point the network reproduces the chain-ladder means exactly, only the output weights of the hidden features have a non-zero gradient, and the first optimiser step moves each of these weights by a fixed amount that does not depend on the size of the gradient. The report further treats the reserves, the dispersion of the network, the diagnostics computed from the fitted means and the handling of periods without payments, and it maps every formula to the place in the code where it is computed. A numerical check on a synthetic triangle, carried out independently of Keras, confirms the formulas to machine precision.

# INTRODUCTION {#d1-ch1}

## Introduction {#d1-s1}

This report writes out, formula by formula, what the code of the blended cross-classified neural network (bCCNN) computes on one $20 \times 20$ annual claims triangle. The bCCNN combines the cross-classified over-dispersed Poisson (ccODP) model, the stochastic model on which the chain ladder rests, with a feed-forward neural network. It follows Gabrielli, Richman and Wüthrich (2020), referred to as Paper C as in the code, and the restatement of Paper C by Härkönen (2021: 12-16). The ccODP model is fitted as a generalised linear model (GLM), and its maximum likelihood estimates (MLEs) become the fixed inputs of the network. The report covers the ccODP model, the neural network that is wrapped around it, the loss as Keras sees it, the gradients, and the properties of the starting point of gradient descent with the root mean square propagation (RMSprop) optimiser. The code that is explained is `fit_odp_glm()` in `R/fit ODP GLM`, `bccnn_model()` and `fit_bccnn()` in `R/nn_models.R`, the files `R/loss functions.R` and `R/metrics.R`, and the script `analysis/03_bCCNN/bCCNN fit.R`.

The report is the first of four companion explainers, referred to below as companions I to IV. Companion I is this document, *The mathematics behind the bCCNN*. Companion II, *The fitting procedure and training of the bCCNN*, describes which cells train the network, which cells stop the training and how the final network is chosen. Companion III, *The bCCNN as a whole: interpretation, evaluation and uncertainty*, joins the others and treats interpretation, evaluation and uncertainty. Companion IV, *The time-aware split for the bCCNN*, describes the rolling-origin split. The four documents share the notation summarised in the List of symbols (Appendix ⟦ref:d1-appA⟧).

The question addressed is what, exactly, the network computes and why it starts at the chain ladder: which model the network embeds, which criterion it minimises, how the gradient flows at the start and how far the first steps move the parameters, and how the reserves, the dispersion and the diagnostics follow from the fitted means. Each answer is stated as a formula, derived where it is not standard, and linked to the place in the code that computes it.

Three elements of the code are not in Paper C and are marked where they appear: the rolling-origin early stopping, which draws on Al-Mudafer, Avanzi, Taylor and Wong (2021) and is described in companions II and IV; the use of Keras's default initialiser for the hidden layers (Section ⟦ref:d1-s4.6⟧, marked `INFERRED` in a comment of the script `bCCNN fit.R`); and the handling of accident or development periods without payments (Section ⟦ref:d1-s3.9⟧), which is in neither Paper C nor Härkönen (2021).

## The claims triangle {#d1-s2}

The simulated portfolio has $n = 20$ accident periods (years) $i = 1, \dots, n$ and $n$ development periods $j = 1, \dots, n$. A cell $(i, j)$ holds the incremental payments $Y_{i,j}$ made in development period $j$ on claims of accident period $i$, that is, in calendar period

$$
k = i + j - 1 .
$$
⟦eq:d1-eq1⟧

At the valuation date, calendar period $n$, the observed cells are those with $k \le n$ and the future cells those with $k > n$:

$$
\begin{aligned}
&\mathcal{O} = \{(i, j) : i + j \le n + 1\}, \qquad \mathcal{F} = \{(i, j) : i + j > n + 1\}, \\
&|\mathcal{O}| = \tfrac{n(n+1)}{2} = 210, \qquad |\mathcal{F}| = 190 .
\end{aligned}
$$
⟦eq:d1-eq2⟧

The quantity to predict is the sum of the future cells, the outstanding payments to development period $n$,

$$
R = \sum_{(i, j) \in \mathcal{F}} Y_{i,j}, \qquad R_i = \sum_{j > n + 1 - i} Y_{i,j} .
$$
⟦eq:d1-eq3⟧

In the simulated data $R$ is known: `triangle_sets()` returns it as the matrix `test` (the lower triangle, `NA` above the diagonal). Payments after development period $n$ exist in the simulation but are in no triangle and no model; they are returned apart as `tail_o` and reported on their own row of the results table. The simulator's `triangle.csv` folds them into column $n$, which for accident period 1 is an observed cell; the script checks that folding and then uses the triangles of `triangle_sets()`, which stop at development period $n$.

In the code the square `sets$full` holds all $Y_{i,j}$, `sets$upper` holds $\mathcal{O}$ (future cells `NA`), and every amount is divided by $u = 10^6$ before fitting (`dat_cfg$scale`), so that the fit runs in millions; Section ⟦ref:d1-s3.8⟧ shows that this changes nothing but the intercept.

## Verification of the mathematics {#d1-ch1-check}

Every formula of Chapters ⟦ref:d1-ch2⟧ to ⟦ref:d1-ch5⟧ was recomputed in plain numpy, without Keras, on a synthetic $20 \times 20$ triangle with the dimensions of the data of the study (210 observed cells, payments in millions), and the two implementations were compared. # THE CROSS-CLASSIFIED OVER-DISPERSED POISSON MODEL {#d1-ch2}

## Introduction {#d1-ch2-intro}

Chapter ⟦ref:d1-ch1⟧ defined the claims triangle and the quantity to predict. This chapter sets out the ccODP model from which the bCCNN starts: its assumptions and identification, the Poisson deviance by which it is fitted, the maximum likelihood equations and the way `glm()` solves them, the proof that the fitted model reproduces the chain-ladder reserve, the estimation of the dispersion, the effect of the unit of the payments and the treatment of periods without payments. The marginal-total equations derived here are used again in Chapter ⟦ref:d1-ch4⟧ to explain the gradient at the start of the training.

## Assumptions {#d1-s3.1}

The assumptions are those of Section 2 of Paper C and of Härkönen (2021: 5), her equations (1) to (3). The incremental payments of the observed cells are independent, with

$$
\begin{aligned}
&\mathbb{E}[Y_{i,j}] = \mu_{i,j} = \exp\{ c + \alpha_i + \beta_j \}, \\
&\operatorname{Var}(Y_{i,j}) = \phi\, \mu_{i,j}, \qquad \phi > 0 .
\end{aligned}
$$
⟦eq:d1-eq4⟧

The model is called 'cross-classified' because the two factors, accident period and development period, enter additively on the log scale: every accident period has the same development pattern $(e^{\beta_j})_j$, scaled by its own level $e^{c + \alpha_i}$. No interaction between $i$ and $j$ is allowed; that is exactly what the network of Chapter ⟦ref:d1-ch3⟧ adds.

The term 'over-dispersed Poisson' means that the variance is $\phi$ times the mean instead of equal to it. A concrete distribution with these moments is the scaled Poisson $Y = \phi P$ with $P \sim \mathrm{Poisson}(\mu / \phi)$: then $\mathbb{E}[Y] = \phi \cdot \mu / \phi = \mu$ and $\operatorname{Var}(Y) = \phi^2 \cdot \mu / \phi = \phi \mu$. The fit, however, uses only the first two moments: it is a quasi-likelihood fit (`family = quasipoisson(link = "log")`), and $\phi$ is estimated afterwards (Section ⟦ref:d1-s3.7⟧). The payments must be non-negative, and `fit_odp_glm()` stops if an observed increment is negative. Härkönen (2021: 28) replaces negative aggregated payments by zero; the simulated triangle has none.

## Identification {#d1-s3.2}

The linear predictor $c + \alpha_i + \beta_j$ has $1 + n + n$ coefficients, but only $2n - 1$ of them are identifiable: adding a constant to all $\alpha_i$ and subtracting it from $c$ changes nothing, and likewise for the $\beta_j$. Paper C's equation (3) fixes

$$
\alpha_1 = \beta_1 = 0,
$$
⟦eq:d1-eq5⟧

so that $c$ is the log mean of cell $(1, 1)$, $\alpha_i$ is the log ratio of accident period $i$ to accident period 1 at the same development period, and $\beta_j$ is the log ratio of development period $j$ to development period 1 within an accident period. In `fit_odp_glm()` this is the treatment contrasts of R for `y ~ origin + dev`, with `origin` and `dev` as factors whose first level is period 1: the intercept is $c$, the coefficient `origin`$i$ is $\alpha_i$ and `dev`$j$ is $\beta_j$. The number of parameters is

$$
n_{\mathrm{par}} = 1 + (n - 1) + (n - 1) = 2n - 1 = 39,
$$
⟦eq:d1-eq6⟧

against $n_{\mathrm{obs}} = |\mathcal{O}| = 210$ fitted cells on the full triangle.

## The Poisson deviance {#d1-s3.3}

For a mean vector $\boldsymbol\mu$ and a set of cells $\mathcal{S}$, the (unscaled) Poisson deviance is Paper C's equation (4):

$$
\begin{aligned}
&D(\boldsymbol{y}, \boldsymbol{\mu}; \mathcal{S}) = 2 \sum_{(i, j) \in \mathcal{S}} \Big( \mu_{i,j} - y_{i,j} + y_{i,j} \log \frac{y_{i,j}}{\mu_{i,j}} \Big), \\
&0 \log 0 := 0 .
\end{aligned}
$$
⟦eq:d1-eq7⟧

It is `poisson_deviance(y, mu)` in `R/loss functions.R`, which drops the cells where `y` is `NA`; that is how the same function scores the observed triangle, a validation mask or the true lower triangle. Each summand is non-negative and zero only when $\mu_{i,j} = y_{i,j}$, because $x \mapsto \mu - x + x \log(x / \mu)$ is the Bregman divergence of $x \log x$.

*Where it comes from.* The Poisson log-likelihood of the observed cells, with the means scaled by $\phi$ as in the scaled-Poisson representation, is up to a constant

$$
\ell(\boldsymbol\mu) = \frac{1}{\phi} \sum_{\mathcal{S}} \big( y_{i,j} \log \mu_{i,j} - \mu_{i,j} \big) .
$$
⟦eq:d1-eq8⟧

The saturated model sets $\mu_{i,j} = y_{i,j}$ and attains $\ell_{\mathrm{sat}} = \frac{1}{\phi} \sum (y \log y - y)$. Twice the gap, times $\phi$, is ⟦ref:d1-eq7⟧:

$$
D = 2 \phi \big( \ell_{\mathrm{sat}} - \ell(\boldsymbol\mu) \big) .
$$
⟦eq:d1-eq9⟧

Since $\phi$ only multiplies the whole log-likelihood, maximising ⟦ref:d1-eq8⟧ and minimising ⟦ref:d1-eq7⟧ give the same $\hat{\boldsymbol\mu}$ for every $\phi$: the dispersion plays no part in the point estimates, a remark that Härkönen (2021: 5) also makes. This is why the network can use the deviance as its loss and still estimate $\phi$ separately.

## The maximum likelihood equations {#d1-s3.4}

Write $a_{i,j} = \log \mu_{i,j} = c + \alpha_i + \beta_j$. Differentiating one summand of ⟦ref:d1-eq7⟧ in $a_{i,j}$ gives

$$
\frac{\partial}{\partial a_{i,j}} \, 2 \Big( e^{a_{i,j}} - y_{i,j} + y_{i,j} \log y_{i,j} - y_{i,j} a_{i,j} \Big) = 2 \big( \mu_{i,j} - y_{i,j} \big) .
$$
⟦eq:d1-eq10⟧

By the chain rule, with $\partial a_{i,j} / \partial c = 1$, $\partial a_{i,j} / \partial \alpha_{i'} = \mathbf{1}\{i = i'\}$ and $\partial a_{i,j} / \partial \beta_{j'} = \mathbf{1}\{j = j'\}$,

$$
\begin{aligned}
\frac{\partial D}{\partial c} &= 2 \sum_{(i,j) \in \mathcal{O}} (\mu_{i,j} - y_{i,j}), \\
\frac{\partial D}{\partial \alpha_{i}} &= 2 \sum_{j \le n + 1 - i} (\mu_{i,j} - y_{i,j}), \\
\frac{\partial D}{\partial \beta_{j}} &= 2 \sum_{i \le n + 1 - j} (\mu_{i,j} - y_{i,j}) .
\end{aligned}
$$
⟦eq:d1-eq11⟧

At the MLE all of these vanish: for $i, j \ge 2$ directly, and for $i = 1$ and $j = 1$ because the total minus the others vanishes too. The fitted ccODP therefore reproduces every observed row total and every observed column total of the triangle:

$$
\begin{aligned}
\sum_{j \le n + 1 - i} \hat\mu^{\mathrm{cc}}_{i,j} &= \sum_{j \le n + 1 - i} y_{i,j} \qquad (i = 1, \dots, n), \\
\sum_{i \le n + 1 - j} \hat\mu^{\mathrm{cc}}_{i,j} &= \sum_{i \le n + 1 - j} y_{i,j} \qquad (j = 1, \dots, n) .
\end{aligned}
$$
⟦eq:d1-eq12⟧

This 'marginal totals' property is the whole reason why the ccODP is the chain ladder (Section ⟦ref:d1-s3.6⟧), and it is also why two of the gradients of the network vanish at the start (Section ⟦ref:d1-s6.4⟧). The numerical check finds the row and column sums of $\hat\mu - y$ at $10^{-11}$.

## How glm() solves them: IWLS {#d1-s3.5}

`stats::glm()` solves ⟦ref:d1-eq11⟧ by Fisher scoring, which for a GLM is IWLS (McCullagh and Nelder, 1989). With the design matrix $X$ ($210 \times 39$: a column of ones, 19 accident-period dummies and 19 development-period dummies) and the coefficient vector $\vartheta = (c, \alpha_2, \dots, \alpha_n, \beta_2, \dots, \beta_n)$, each iteration computes, from the current $\vartheta$,

$$
\begin{aligned}
&\eta = X \vartheta, \qquad \mu = e^{\eta}, \qquad z = \eta + \frac{y - \mu}{\mu} \ \ \text{(working response)}, \\
&W = \operatorname{diag}(\mu) \ \ \text{(working weights)}, \\
&\vartheta_{\mathrm{new}} = (X^\top W X)^{-1} X^\top W z .
\end{aligned}
$$
⟦eq:d1-eq13⟧

For the log link the working weight $\mu$ comes from $(\partial\mu/\partial\eta)^2 / \operatorname{Var} = \mu^2 / \mu$. The code runs the iteration with `glm.control(epsilon = 1e-12, maxit = 100)`, so the relative change of the deviance between iterations has to fall below $10^{-12}$; it warns if that is not reached and stops if a coefficient is `NA` (the fitted cells then do not connect all periods). The same routine fits a subset of the observed cells when a `cells` mask is given (rolling-origin partitions); then ⟦ref:d1-eq11⟧ and ⟦ref:d1-eq12⟧ hold over the fitted cells only.

## The ccODP is the chain ladder {#d1-s3.6}

*Statement.* Let $\hat\mu^{\mathrm{cc}}$ be the ccODP MLE on the full observed triangle, and define the fitted and predicted cumulative payments $\hat C_{i,j} = \sum_{l \le j} \hat\mu^{\mathrm{cc}}_{i,l}$. Then $\hat C_{i,n}$ equals the chain-ladder ultimate of accident period $i$, that is, the latest cumulative payment $C_{i, n+1-i} = \sum_{j \le n+1-i} y_{i,j}$ multiplied by the volume-weighted chain-ladder factors,

$$
\begin{aligned}
&\hat C_{i,n} = C_{i, n + 1 - i} \prod_{k = n + 1 - i}^{n - 1} f_k, \\
&f_k = \frac{\sum_{i' \le n - k} C_{i', k + 1}}{\sum_{i' \le n - k} C_{i', k}},
\end{aligned}
$$
⟦eq:d1-eq14⟧

so that the ccODP reserve $\hat R = \sum_{\mathcal{F}} \hat\mu^{\mathrm{cc}}_{i,j}$ is the chain-ladder reserve (Hachemeister and Stanard, 1975; Mack, 1991; Renshaw and Verrall, 1998; Gabrielli *et al.*, 2020). Renshaw and Verrall (1998) is also the general reference of Härkönen (2021: 5) for this model, and Section 2 of Paper C states the result. The script asserts it: `all.equal(res$odp$reserve * scale, cl$total[["ibnr"]])`.

*Proof.* Write $\hat\mu^{\mathrm{cc}}_{i,j} = \hat a_i \hat b_j$ with $\hat a_i = e^{\hat c + \hat\alpha_i}$ and $\hat b_j = e^{\hat\beta_j}$, and $S_k = \sum_{j \le k} \hat b_j$, so that $\hat C_{i,k} = \hat a_i S_k$. Fix $k \in \{2, \dots, n\}$.

*Step 1.* Sum the column equations of ⟦ref:d1-eq12⟧ over the columns $1, \dots, k$. The cells involved are the observed cells in those columns. They split into the rows $i \le n + 1 - k$, for which all cells $(i, 1), \dots, (i, k)$ are observed, and the rows $i \ge n + 2 - k$, whose observed cells all lie in columns $\le n + 1 - i \le k - 1$, so that the whole observed row is included. For those later rows the row equations of ⟦ref:d1-eq12⟧ state that the fitted row total equals the observed row total; subtracting them leaves

$$
\sum_{i \le n + 1 - k} \hat C_{i,k} = \sum_{i \le n + 1 - k} C_{i,k} .
$$
⟦eq:d1-eq15⟧

*Step 2.* Apply ⟦ref:d1-eq15⟧ with $k - 1$ in place of $k$: it runs over the rows $i \le n + 2 - k$. The extra row $i = n + 2 - k$ has observed cells exactly up to column $k - 1$, so its row equation reads $\hat C_{n+2-k, k-1} = C_{n+2-k, k-1}$. Subtracting it gives

$$
\sum_{i \le n + 1 - k} \hat C_{i,k-1} = \sum_{i \le n + 1 - k} C_{i,k-1} .
$$
⟦eq:d1-eq16⟧

*Step 3.* Divide ⟦ref:d1-eq15⟧ by ⟦ref:d1-eq16⟧: the right-hand side is the chain-ladder factor $f_{k-1}$ of ⟦ref:d1-eq14⟧; the left-hand side is $\hat a_\bullet S_k / (\hat a_\bullet S_{k-1})$ with $\hat a_\bullet = \sum_{i \le n+1-k} \hat a_i$. Hence

$$
\frac{S_k}{S_{k-1}} = f_{k-1}, \qquad k = 2, \dots, n .
$$
⟦eq:d1-eq17⟧

*Step 4.* The row equation of ⟦ref:d1-eq12⟧ for accident period $i$ states that $\hat a_i S_{n+1-i} = C_{i, n+1-i}$. Therefore $\hat C_{i,n} = \hat a_i S_n = C_{i,n+1-i} \, S_n / S_{n+1-i} = C_{i,n+1-i} \prod_{k=n+2-i}^{n} S_k / S_{k-1}$, which by ⟦ref:d1-eq17⟧ is ⟦ref:d1-eq14⟧. $\square$

Two consequences are used later. First, ⟦ref:d1-eq17⟧ states that the fitted development pattern of the ccODP is the chain-ladder pattern, the same for every accident period (Section ⟦ref:d1-s9⟧). Second, the proof uses only the marginal-total equations ⟦ref:d1-eq12⟧; the bCCNN does not satisfy them after the first gradient step, so its reserve is no longer a chain-ladder reserve.

## Dispersion {#d1-s3.7}

The point estimates do not need $\phi$, but the variance ⟦ref:d1-eq4⟧, the Pearson residuals and any standard error do. `fit_odp_glm()` returns both usual estimators, with the degrees of freedom $n_{\mathrm{obs}} - n_{\mathrm{par}} = 210 - 39 = 171$ on the full triangle:

$$
\begin{aligned}
\hat\phi_D &= \frac{D(\boldsymbol{y}, \hat{\boldsymbol\mu}^{\mathrm{cc}}; \mathcal{O})}{n_{\mathrm{obs}} - n_{\mathrm{par}}}, \\
\hat\phi_P &= \frac{1}{n_{\mathrm{obs}} - n_{\mathrm{par}}} \sum_{\mathcal{O}} \frac{(y_{i,j} - \hat\mu^{\mathrm{cc}}_{i,j})^2}{\hat\mu^{\mathrm{cc}}_{i,j}} .
\end{aligned}
$$
⟦eq:d1-eq18⟧

The deviance estimator $\hat\phi_D$ is Paper C's equation (5) and the default of the code. Both are moment estimators of the ratio of variance to mean: under ⟦ref:d1-eq4⟧ each Pearson term has expectation about $\phi$, and the deviance term agrees with it to second order. `config.yml` selects `odp: phi: deviance`. The dispersion of the bCCNN is a separate matter (Section ⟦ref:d1-s8⟧).

## The unit of the payments {#d1-s3.8}

The fit runs on $y / u$ with $u = 10^6$. Let $\boldsymbol\mu'$ be the MLE on $\boldsymbol y' = \boldsymbol y / u$. Since $\log(\mu_{i,j} / u) = (c - \log u) + \alpha_i + \beta_j$, the scaled model is the same model with the intercept shifted, and the deviance scales linearly:

$$
\begin{aligned}
&D(\boldsymbol{y} / u, \boldsymbol\mu / u) = \frac{1}{u} D(\boldsymbol{y}, \boldsymbol\mu), \qquad \text{so} \\
&\hat c' = \hat c - \log u, \quad \hat\alpha' = \hat\alpha, \quad \hat\beta' = \hat\beta, \\
&\hat{\boldsymbol\mu}' = \hat{\boldsymbol\mu} / u, \quad \hat R' = \hat R / u, \quad \hat\phi' = \hat\phi / u .
\end{aligned}
$$
⟦eq:d1-eq19⟧

The Pearson residual $(y - \mu) / \sqrt{\phi \mu}$ is invariant ($u$ cancels), and so is the relative difference $\mu^{\mathrm{bCCNN}} / \mu^{\mathrm{cc}} - 1$. The numerical check confirms ⟦ref:d1-eq19⟧ to $10^{-13}$. For the network the unit matters only through the fixed inputs: $\alpha_i$ and $\beta_j$ do not change with $u$, so the hidden layers see the same inputs whatever the unit, and the output intercept starts at $\hat c'$. Unlike the steps of stochastic gradient descent (SGD), the steps of RMSprop are (almost) invariant to the scale of the gradient (companion II, Section ⟦ref:d2-s5⟧), so the choice of unit changes the training very little.

## Periods without payments {#d1-s3.9}

### What happens {#d1-s3.9-what}

If an accident period or a development period has no payments in the fitted cells, its MLE is $-\infty$. In the row or column equation ⟦ref:d1-eq12⟧ the fitted means of that period must sum to zero, which only $e^{-\infty} = 0$ achieves, so the deviance keeps decreasing as the effect goes to $-\infty$. `glm()` stops at a large negative value (about $-30$) that it reports as converged, with fitted means of order $e^{-30}$. `fit_odp_glm()` flags these periods as `zero_origin` and `zero_dev` and warns.

### Why it is harmless for the chain ladder {#d1-s3.9-harmless}

A development period with no payments has a chain-ladder factor of exactly 1, and the ccODP limit $\mu = 0$ for that column predicts the same. The difficulty is purely numerical, and it matters in two places.

*As a network input.* The embedding of that period is then $\approx -30$, far outside the range of the other effects (companion II, Section ⟦ref:d2-s6⟧, on the raw inputs). The hidden layers see a value they were never trained near.

*In the deviance.* A cell with $y > 0$ scored against $\mu \approx e^{-30}$ adds $y \log(y / \mu) \approx 30\, y$ to the deviance. One such cell can dominate a validation or test loss: in the check of the code change, a single validation cell raised the starting validation deviance of a partition from $32$ to $3\ 047$. `poisson_deviance()` does not catch it, because $e^{-30}$ is positive and finite.

### What Paper C and Härkönen do {#d1-s3.9-papers}

Neither discusses it. Härkönen replaces negative aggregated payments with zero so that the Poisson loss applies (Härkönen, 2021: 28, 45; her Sections 3.1 and 4.1), which makes every cell valid but does nothing about a period whose payments sum to zero. When she removes the last diagonal she notes that the networks "require input values for each accident year, reporting delay and payment delay" and declares them "not applicable" (Härkönen, 2021: 37), instead of handling the gap. Her triangles have 12 accident years and portfolios of about 100 000 to over a million claims (Härkönen, 2021: 27, 45), and Paper C's six simulated LoBs are of the same kind, so every period has payments in both halves of their balanced claims splits. Paper C's Listing 4 sets the embeddings to the GLM estimates with no guard. Paper C is cited here through the quotations in the literature notes in the repository (thesis/Hyperparameter search).

### What the code does {#d1-s3.9-code}

The helper `mask_zero_periods(m, fit)` in `R/nn_models.R` sets to `NA` the cells of `m` in the periods that `fit` flags, so that they are left out of the deviance:

- Under the claims split, `bccnn_validation()` masks the validation cells in periods with no payments in the training half (companion II, Section ⟦ref:d2-s3.3⟧);
- Under the rolling origin, `bccnn_ro_partition()` masks the validation cells in periods with no payments in the training cells of the partition, and the test cells in periods with no payments in *any* cell observed at the valuation date (companion IV, Sections ⟦ref:d4-s7⟧ and ⟦ref:d4-s8⟧); `n_vali` and `n_test` count the cells actually scored.

The network input itself is left as it is. On the full annual triangle every period has payments; whether a training half or a rolling-origin partition has an empty period depends on how sparse the last development years are.

## Summary {#d1-ch2-summary}

The ccODP model describes each cell by an intercept, an accident-period effect and a development-period effect on the log scale, with a variance proportional to the mean. It is fitted by minimising the Poisson deviance, which gives the same point estimates for every dispersion, and `glm()` finds the minimum by IWLS. The maximum likelihood equations state that the fitted model reproduces every observed row and column total, and these marginal totals alone imply that the ccODP reserve is the chain-ladder reserve and that its development pattern is the chain-ladder pattern. The dispersion is estimated afterwards from the deviance or the Pearson statistic, the unit of the payments shifts only the intercept, and periods without payments produce effects of about $-30$ that the code masks out of the deviance but leaves in the network input. Chapter ⟦ref:d1-ch3⟧ wraps a neural network around this model and starts it exactly at the ccODP fit.

# THE bCCNN NETWORK AND ITS LOSS {#d1-ch3}

## Introduction {#d1-ch3-intro}

Chapter ⟦ref:d1-ch2⟧ established that the fitted ccODP is the chain ladder. This chapter describes the network that the bCCNN wraps around it, following Section 3 and Listing 4 of Paper C and Härkönen (2021: 12-16): the embedding layers that hold the ccODP effects, the skip connection that carries the ccODP linear predictor to the output, the feed-forward part, the output neuron, dropout and the initialisation at the ccODP fit. It closes with the loss that Keras minimises and with what the code records after each gradient step.

Figure ⟦ref:d1-fig1⟧ draws the network with the layer names of `bccnn_model()`. The green path is the skip connection, which carries the ccODP linear predictor unchanged to the output; the orange path is the feed-forward network; the output neuron adds the two on the log scale and exponentiates.

## Embedding layers {#d1-s4.1}

The inputs are the categorical accident period and development period of a cell, passed to Keras as the 0-based integers $i - 1$ and $j - 1$ (`bccnn_inputs()`). An embedding layer maps a category to a vector; here each vector is one-dimensional and holds the ccODP effect of that period (Paper C's equations (9) and (10); Härkönen, 2021: 13, her equations (33) and (34)):

$$
\text{AY\_embed}: \ i \mapsto \hat\alpha_i, \qquad \text{DY\_embed}: \ j \mapsto \hat\beta_j .
$$
⟦eq:d1-eq20⟧

The two embedding matrices ($20 \times 1$ each, 40 numbers) are set to the MLE with `set_weights()` and frozen (`trainable = trainable_embeddings`, `false` in `config.yml`), as Härkönen does and as Paper C's Listing 4 does. If they were trainable, 40 parameters would be added to $\theta$ and the skip connection would stop being exactly the ccODP after the first step; Härkönen (2021: 33-34) reports that the predictions then improved for some LoBs at a higher computation cost (her rows labelled TW, for trainable input weights). Everything below assumes that the embeddings are fixed.

## The skip connection {#d1-s4.2}

`cc0 = layer_add(AY_flat, DY_flat)` is the ccODP linear predictor without its intercept,

$$
\mathrm{cc}_0(i, j) = \hat\alpha_i + \hat\beta_j .
$$
⟦eq:d1-eq21⟧

It goes straight to the output neuron (the green path of Figure ⟦ref:d1-fig1⟧). This is Härkönen's 'skip-connection' (Härkönen, 2021: 12, 18) and Paper C's 'embedding' of the ccODP: the classical model is a sub-network of the bCCNN.

## The feed-forward part {#d1-s4.3}

The same two numbers are also concatenated into the input of a feed-forward network,

$$
z^{(0)}(i, j) = (\hat\alpha_i, \hat\beta_j)^\top \in \mathbb{R}^2,
$$
⟦eq:d1-eq22⟧

followed by three dense layers with hyperbolic tangent activation and $q_1 = 20$, $q_2 = 15$ and $q_3 = 10$ neurons (Härkönen, 2021: 14, her equation (40); Paper C, Listing 4):

$$
z^{(h)}(i, j) = \tanh\!\Big( b^{(h)} + W^{(h)\top} z^{(h-1)}(i, j) \Big) \in \mathbb{R}^{q_h}, \qquad h = 1, 2, 3,
$$
⟦eq:d1-eq23⟧

where $\tanh$ acts component-wise, $W^{(h)} \in \mathbb{R}^{q_{h-1} \times q_h}$ and $b^{(h)} \in \mathbb{R}^{q_h}$. A dropout layer with rate $p = 0.1$ follows each hidden layer (Section ⟦ref:d1-s4.5⟧). Härkönen (2021: 15) gives two reasons for $\tanh$: its derivative is $1 - \tanh^2$, cheap to compute from the activation itself (Section ⟦ref:d1-s6.3⟧), and its range $(-1, 1)$ keeps the activations bounded.

The trainable parameters are counted in Table ⟦ref:d1-tab1⟧, which follows Härkönen's (2021: 23) count, her equation (76), with $q_0 = 2$ and $q_4 = 1$, plus the skip weight. The total of 547 agrees with the `summary()` of the model in Keras, where the 40 embedding numbers appear as non-trainable.

| Layer | Input $\times$ output | Weights | Biases | Trainable parameters |
|:--|:--|--:|--:|--:|
| `hidden1` | $2 \times 20$ | 40 | 20 | 60 |
| `hidden2` | $20 \times 15$ | 300 | 15 | 315 |

## The output neuron {#d1-s4.4}

`concate1` joins the skip connection and the last hidden layer into an 11-vector $(\mathrm{cc}_0(i,j), z^{(3)}(i,j)) \in \mathbb{R}^{11}$, and `Response` is a dense layer with one neuron and exponential activation. Writing its 11 weights as $(w, B)$, with $w \in \mathbb{R}$ on the skip connection and $B \in \mathbb{R}^{10}$ on the hidden features, and its bias as $c$, the mean of the network for cell $(i, j)$ is Paper C's equation (13):

$$
\begin{aligned}
\mu_{i,j}(\theta) &= \exp\Big\{ \underbrace{w \, (\hat\alpha_i + \hat\beta_j)}_{\text{skip connection}} + \underbrace{c + \langle B, z^{(3)}(i, j) \rangle}_{\text{network}} \Big\}, \\
a_{i,j} &:= \log \mu_{i,j} .
\end{aligned}
$$
⟦eq:d1-eq24⟧

Paper C keeps $w$ trainable, as `bccnn_model()` does; the comment in the script `bCCNN fit.R` describes this as "exactly as Listing 4 does". Härkönen (2021: 15), her equation (44), writes the skip connection with weight 1. Both views of ⟦ref:d1-eq24⟧ are useful.

*Multiplicative boosting.* Factoring out the ccODP mean gives $\mu_{i,j} = \hat\mu^{\mathrm{cc}}_{i,j} \cdot \exp\{ (w - 1)(\hat\alpha_i + \hat\beta_j) + (c - \hat c) + \langle B, z^{(3)}(i,j) \rangle \}$. The network learns a multiplicative correction of the chain-ladder means, which is 1 at the start. This is the combined actuarial neural network (CANN) idea of Wüthrich and Merz (2019), on which Härkönen (2021: 4) also draws, and what Paper C calls "neural network boosting" (Gabrielli *et al.*, 2018: 14).

*A function of two scalars.* The feed-forward part sees only $(\hat\alpha_i, \hat\beta_j)$. Whatever it learns is a smooth surface $g(\alpha, \beta)$ evaluated at the 20 accident effects and the 20 development effects. Two accident periods with equal $\hat\alpha$ receive the same correction at every development period; the correction for a future cell $(i, j)$ is the surface at the pair $(\hat\alpha_i, \hat\beta_j)$, a combination never seen in training even though each coordinate was. What the network can add to the ccODP is therefore exactly an interaction between the accident-period effect and the development-period effect, that is, accident-period-dependent development patterns (Section ⟦ref:d1-s9⟧, cumulative factors).

## Dropout {#d1-s4.5}

The dropout of Keras is 'inverted dropout' (Srivastava, Hinton, Krizhevsky, Sutskever and Salakhutdinov, 2014; Härkönen, 2021: 12, her equations (31) and (32)). During training, after each hidden layer a mask of independent Bernoulli variables is drawn and the surviving activations are scaled up so that their expectation is unchanged:

$$
\begin{aligned}
&\tilde z^{(h)} = \frac{z^{(h)} \odot m^{(h)}}{1 - p}, \qquad m^{(h)}_r \sim \mathrm{Bernoulli}(1 - p) \ \text{independently}, \\
&\mathbb{E}[\tilde z^{(h)} \mid z^{(h)}] = z^{(h)} .
\end{aligned}
$$
⟦eq:d1-eq25⟧

The next layer reads $\tilde z^{(h)}$ in place of $z^{(h)}$ in ⟦ref:d1-eq23⟧, and the output neuron reads $\tilde z^{(3)}$ in ⟦ref:d1-eq24⟧. At prediction time (`predict_on_batch`, `predict`) no mask is drawn and ⟦ref:d1-eq23⟧ and ⟦ref:d1-eq24⟧ hold as written. This has two consequences for what the code records (Section ⟦ref:d1-s5.2⟧): the loss that Keras prints during training is the loss of a randomly thinned network, and it is reported as the column `train_dropout`; the deviances in the columns `train`, `vali`, `test` and `truth` are computed from `predict_on_batch()` after each step, without dropout. Paper C's Figure 2 shows the first kind of curve (noisy), and Paper C's Table 3 reports both kinds. Härkönen's (2021: 12) remark on dropout, that each neuron must learn features that are useful without relying on particular other neurons, is the reason why it regularises a network with 547 parameters on 210 cells.

## The initialisation {#d1-s4.6}

Keras builds the model with its default initialisers: Glorot-uniform weights, $W^{(h)}_{r,s} \sim \mathrm{U}(-\lambda_h, \lambda_h)$ with $\lambda_h = \sqrt{6 / (q_{h-1} + q_h)}$, and zero biases, for the three hidden layers and for `Response`; `set_random_seed(seed)` fixes the draw. Then `bccnn_model()` overwrites the embeddings and the output neuron, which gives the start of gradient descent of Paper C's equation (14):

$$
\begin{aligned}
\theta_0: \qquad &\text{AY\_embed} = \hat\alpha, \qquad \text{DY\_embed} = \hat\beta, \\
&w = 1, \qquad c = \hat c, \qquad B = 0 \in \mathbb{R}^{10}, \\
&(W^{(h)}, b^{(h)}) \ \text{random: Glorot-uniform weights, zero biases}, \qquad h = 1, 2, 3 .
\end{aligned}
$$
⟦eq:d1-eq26⟧

*Property 1: the start is the ccODP model.* With $B = 0$ the hidden layers do not reach the output, whatever their random weights, and ⟦ref:d1-eq24⟧ becomes $\mu_{i,j}(\theta_0) = \exp\{ \hat\alpha_i + \hat\beta_j + \hat c \} = \hat\mu^{\mathrm{cc}}_{i,j}$ for every cell, observed or future. Hence the deviance at step 0 equals the ccODP deviance, the reserve at step 0 equals the chain-ladder reserve (Section ⟦ref:d1-s3.6⟧), and every cumulative development factor at step 0 is the chain-ladder factor. The record at `epoch = 0` of the history is this start. Keras holds the weights in single precision, so in R the equality holds to about $10^{-7}$ relative; in the double-precision check it holds to $10^{-14}$.

This is what makes the bCCNN a calibration of the chain ladder rather than a new model: the number of gradient steps measures how far the network is allowed to move away from the chain ladder, and $t^* = 0$ returns the chain ladder itself.

*The initialiser of the hidden layers.* A comment marked `INFERRED` in the script `bCCNN fit.R` records that the Python version of the single bCCNN used the default initialiser of torch, $\mathrm{U}(\pm 1/\sqrt{\text{fan-in}})$, for the hidden layers, and observes that it leaves the chain ladder about three times more slowly. The reason is visible in Section ⟦ref:d1-s6.4⟧: the only non-zero gradient at the start is the one in $B$, and it is proportional to the hidden activations $z^{(3)}$; smaller initial weights make $z^{(3)}$ smaller and closer to zero, so the first steps add less. Paper C's own default is that of Keras, which the R code keeps.

## The loss as Keras sees it {#d1-s5}

### Keras's Poisson loss and the deviance {#d1-s5.1}

`compile(loss = "poisson")` minimises the mean over the $N$ training cells of $\mu - y \log(\mu + \varepsilon)$, with the small constant $\varepsilon = 10^{-7}$ of Keras inside the logarithm,

$$
\ell(\theta) = \frac{1}{N} \sum_{r = 1}^{N} \Big( \mu_r(\theta) - y_r \log \big( \mu_r(\theta) + \varepsilon \big) \Big) .
$$
⟦eq:d1-eq27⟧

Dropping $\varepsilon$ (its effect on $\ell$ is below $10^{-7}$ here), ⟦ref:d1-eq27⟧ and the deviance ⟦ref:d1-eq7⟧ over the same cells differ by a constant that does not depend on $\theta$:

$$
D(\boldsymbol y, \boldsymbol\mu(\theta); \mathcal{S}) = 2 N \, \ell(\theta) + 2 \sum_{r = 1}^{N} \big( y_r \log y_r - y_r \big) .
$$
⟦eq:d1-eq28⟧

Minimising the loss of Keras is therefore minimising the Poisson deviance, the same criterion by which the ccODP was fitted (Paper C, Section 3.3; Härkönen, 2021: 21, her equation (72)), and the gradients differ only by the factor $2N$. The function `keras_poisson_to_deviance(loss, y)` is ⟦ref:d1-eq28⟧; the code applies it to the loss that Keras reports after each epoch to obtain the column `train_dropout` in the units of the other columns.

### What is recorded after every step {#d1-s5.2}

`fit_bccnn()` keeps every cell of the $n \times n$ square in `x_all` and the training cells in `x_fit`. After each gradient step a Keras callback runs `predict_on_batch(x_all)` (without dropout), reshapes the result to the $n \times n$ matrix $\mu^{(t)}$ and stores one row of the history, as set out in Table ⟦ref:d1-tab2⟧.

⟦tabcap:d1-tab2|The history recorded by fit_bccnn()⟧

| Column | Formula | Cells |
|:--|:--|:--|
| `epoch` | Step $t$ ($0$ = the ccODP start) | |
| `train_dropout` | $2 N \ell^{\mathrm{drop}}_{t} + 2 \sum (y \log y - y)$, from the loss Keras reported for epoch $t$ (with dropout; computed before the update of that epoch, so it belongs to $\theta_{t-1}$) | Training cells |
| `train` | $D(\boldsymbol y, \mu^{(t)}; \text{training cells})$ | Training cells |
| `vali`, `test`, `truth` | $D(\cdot, \mu^{(t)}; \cdot)$ on the cells of each tracked matrix (`NA` elsewhere) | Validation, test, true lower triangle |
| `*_pred` | $\sum \mu^{(t)}_{i,j}$ over the cells of each tracked matrix | The same |

With `batch_size = NULL` the batch is all $N$ training cells, so one Keras epoch is exactly one gradient-descent step and `epoch` counts steps, as Paper C does when it asks "how many iterations of the gradient descent algorithm we should perform" (Gabrielli *et al.*, 2018: 11). Companion II (Section ⟦ref:d2-s7⟧) uses these columns for the stopping rule.

## Summary {#d1-ch3-summary}

The bCCNN feeds the ccODP effects of a cell, held in two frozen one-dimensional embeddings, both straight to the output through a skip connection and through three hidden layers of 20, 15 and 10 hyperbolic tangent neurons with dropout. The output neuron adds the two paths on the log scale, so the network is the chain ladder multiplied by a correction that depends only on the pair of effects, which makes it an interaction between accident and development periods. With the output weights of the hidden features set to zero, the skip weight to one and the intercept to the ccODP intercept, the network starts exactly at the ccODP means, whatever the random hidden weights. Keras's Poisson loss equals the Poisson deviance up to a constant and the factor $2N$, and the code records the deviances without dropout after every step. Chapter ⟦ref:d1-ch4⟧ derives the gradients of this loss and shows what happens at the first steps from the ccODP start.

# GRADIENTS AND THE START OF GRADIENT DESCENT {#d1-ch4}

## Introduction {#d1-ch4-intro}

Chapter ⟦ref:d1-ch3⟧ defined the network, its start $\theta_0$ and the loss ⟦ref:d1-eq27⟧. This chapter writes out the gradient that Keras computes by automatic differentiation for the loss ⟦ref:d1-eq27⟧; for the deviance it is multiplied by $2N$. Everything is per cell $r = (i, j)$ of the training set, summed over the batch. The chapter then combines the gradient with the marginal-total equations of Chapter ⟦ref:d1-ch2⟧ to show which parameters move at the start, and with the RMSprop update to show how far they move.

## Derivative in the output {#d1-s6.1}

From ⟦ref:d1-eq10⟧ and ⟦ref:d1-eq27⟧, with $a_r = \log \mu_r$,

$$
\delta_r := \frac{\partial \ell}{\partial a_r} = \frac{1}{N} \big( \mu_r - y_r \big) .
$$
⟦eq:d1-eq29⟧

The signal that drives every parameter is the residual $\mu_r - y_r$ of the cell: positive where the network over-predicts, negative where it under-predicts, and zero in a cell that is fitted exactly.

## Output layer {#d1-s6.2}

From ⟦ref:d1-eq24⟧, $\partial a_r / \partial c = 1$, $\partial a_r / \partial w = \hat\alpha_i + \hat\beta_j$ and $\partial a_r / \partial B = \tilde z^{(3)}_r$, so that

$$
\begin{aligned}
&\frac{\partial \ell}{\partial c} = \sum_r \delta_r, \qquad
\frac{\partial \ell}{\partial w} = \sum_r \delta_r \, (\hat\alpha_i + \hat\beta_j), \\
&\frac{\partial \ell}{\partial B} = \sum_r \delta_r \, \tilde z^{(3)}_r \in \mathbb{R}^{10} .
\end{aligned}
$$
⟦eq:d1-eq30⟧

## Hidden layers (back-propagation) {#d1-s6.3}

Let $\gamma^{(h)}_r \in \mathbb{R}^{q_h}$ be the derivative of $\ell$ in the pre-activation $u^{(h)}_r = b^{(h)} + W^{(h)\top} \tilde z^{(h-1)}_r$ of layer $h$. Since $z = \tanh(u)$ has $\partial z / \partial u = 1 - z^2$, and the mask of ⟦ref:d1-eq25⟧ multiplies the activation, back-propagation (Goodfellow, Bengio and Courville, 2016) gives

$$
\begin{aligned}
\gamma^{(3)}_r &= \delta_r \, \Big( B \odot \frac{m^{(3)}_r}{1 - p} \Big) \odot \big( 1 - z^{(3)2}_r \big), \\
\gamma^{(h)}_r &= \Big( W^{(h+1)} \gamma^{(h+1)}_r \odot \frac{m^{(h)}_r}{1 - p} \Big) \odot \big( 1 - z^{(h)2}_r \big), \qquad h = 2, 1,
\end{aligned}
$$
⟦eq:d1-eq31⟧

and the parameter gradients are

$$
\begin{aligned}
\frac{\partial \ell}{\partial W^{(h)}} &= \sum_r \tilde z^{(h-1)}_r \, \gamma^{(h)\top}_r \in \mathbb{R}^{q_{h-1} \times q_h}, \qquad
\frac{\partial \ell}{\partial b^{(h)}} = \sum_r \gamma^{(h)}_r, \\
&h = 1, 2, 3, \qquad \tilde z^{(0)}_r = z^{(0)}_r .
\end{aligned}
$$
⟦eq:d1-eq32⟧

Without dropout every mask is set to $1 - p$, so that the factors $m / (1 - p)$ become 1. The numerical check compares ⟦ref:d1-eq30⟧ to ⟦ref:d1-eq32⟧ (without dropout) with central finite differences of the deviance at the start and at a random point: the largest relative error over all nine parameter groups is $1.1 \times 10^{-6}$ (in $W^{(3)}$), and the others are at $10^{-7}$ or below (Section ⟦ref:d1-s11⟧).

## Property 2: the gradient at the start {#d1-s6.4}

At $\theta_0$ the means are the ccODP means, so $\delta_r = (\hat\mu^{\mathrm{cc}}_r - y_r) / N$, and the marginal-total equations ⟦ref:d1-eq12⟧ give the following:

- The intercept gradient $\partial \ell / \partial c = \frac{1}{N} \sum_{\mathcal{O}} (\hat\mu^{\mathrm{cc}} - y)$ is zero (the total);
- The skip-weight gradient $\partial \ell / \partial w = \frac{1}{N} \big( \sum_i \hat\alpha_i \sum_{j} (\hat\mu^{\mathrm{cc}}_{i,j} - y_{i,j}) + \sum_j \hat\beta_j \sum_{i} (\hat\mu^{\mathrm{cc}}_{i,j} - y_{i,j}) \big)$ is zero (the row and column totals);
- Every hidden-layer gradient is zero, because $B = 0$ makes $\gamma^{(3)}_r = 0$ in ⟦ref:d1-eq31⟧ and hence $\gamma^{(2)} = \gamma^{(1)} = 0$;
- The gradient $\partial \ell / \partial B = \frac{1}{N} \sum_r (\hat\mu^{\mathrm{cc}}_r - y_r) \, \tilde z^{(3)}_r$ is the only non-zero component.

The first gradient step therefore changes nothing but $B$: it adds to the ccODP log-mean the linear combination $\langle \Delta B, z^{(3)}(i, j) \rangle$ of the ten random hidden features that is most correlated (in the sense of ⟦ref:d1-eq30⟧) with the chain-ladder residuals. This is a boosting step on the residuals of the chain ladder with random features, nothing else. From the second step on, $B \ne 0$ and the gradient flows back into the hidden layers, which then start to shape the features themselves; $c$ and $w$ also start to move, because the marginal-total equations no longer hold once $B \ne 0$.

Figure ⟦ref:d1-fig2⟧ shows the norms of the nine gradient groups of the loss of Keras at the start and after one and two full-batch RMSprop steps in the numerical check, without dropout; bars missing at step 0 are exactly zero or at machine precision. At step 0 only $B$ is non-zero ($c$ and $w$ are at $10^{-14}$, the hidden layers at exactly 0); after one step all are non-zero, with $c$, $w$ and $B$ two orders of magnitude above the hidden layers.

![](figures/gradient_norms_first_steps.png){width=14cm}

⟦figcap:d1-fig2|Norms of the gradient by parameter group over the first RMSprop steps in the numerical check⟧

This property holds on the full triangle and on the training half of the claims split (the ccODP is refitted on the training cells, so ⟦ref:d1-eq12⟧ holds there). It holds equally for a rolling-origin partition, where the ccODP is fitted on the training cells of the partition by the same `glm()` call: ⟦ref:d1-eq12⟧ then holds over those cells.

## Property 3: the size of the first steps {#d1-s6.5}

The optimiser is RMSprop with the parameterisation of Keras (companion II, Section ⟦ref:d2-s5⟧; Goodfellow *et al.*, 2016): for each coordinate $\vartheta$ of $\theta$ with gradient $g_t$,

$$
\begin{aligned}
&v_t = \rho \, v_{t-1} + (1 - \rho) \, g_t^2, \qquad v_0 = 0, \\
&\vartheta_t = \vartheta_{t-1} - \eta \, \frac{g_t}{\sqrt{v_t} + \epsilon} .
\end{aligned}
$$
⟦eq:d1-eq33⟧

At the first step $v_1 = (1 - \rho) g_1^2$, so the update is $\eta \, g_1 / (\sqrt{1 - \rho}\, |g_1| + \epsilon)$. For every coordinate whose gradient is not tiny ($|g_1| \gg \epsilon / \sqrt{1 - \rho} \approx 3 \times 10^{-7}$) this is

$$
\Delta \vartheta_1 \approx - \frac{\eta}{\sqrt{1 - \rho}} \operatorname{sign}(g_1) = \mp 0.00316,
$$
⟦eq:d1-eq34⟧

independent of the size of the gradient. Hence the first step moves each of the ten coordinates of $B$ by $\pm 0.00316$ exactly, and nothing else (the coordinates $c$ and $w$, whose gradient is $10^{-14}$, move by $\eta g / \epsilon \approx 10^{-10}$). The check reports $\max |\Delta B_1| = 0.0031621$ against $0.0031623$ from ⟦ref:d1-eq34⟧.

Two things follow. First, the early path away from the chain ladder is set by $\eta$, $\rho$ and the random features, not by how badly the chain ladder fits: a triangle that the chain ladder fits well and one that it fits badly both move by the same amount at step 1. Second, because the step is sign-like rather than proportional, the training deviance need not fall at first: in the check it goes $108.967 \to 109.034 \to 109.198 \to 108.973$ over the first three steps before it starts to decrease. The loss curves of Paper C and of the code in the repository start with the same kind of wobble.

## Summary {#d1-ch4-summary}

The gradient of every parameter is driven by the cell residuals $\mu_r - y_r$, passed through the output neuron and, by back-propagation, through the hidden layers. At the ccODP start the marginal-total equations make the gradients in the intercept and the skip weight vanish, and the zero output weights $B$ block every hidden-layer gradient, so the first step changes only $B$: it is a boosting step on the chain-ladder residuals with ten random features. Because the first RMSprop step is sign-like, each coordinate of $B$ moves by $\eta / \sqrt{1 - \rho} \approx 0.00316$ whatever the size of the gradient, and the training deviance may rise for a few steps before it falls. Chapter ⟦ref:d1-ch5⟧ turns the fitted means at the chosen step into reserves, a dispersion and diagnostics.

# RESERVES, DISPERSION AND DIAGNOSTICS {#d1-ch5}

## Introduction {#d1-ch5-intro}

Chapters ⟦ref:d1-ch2⟧ to ⟦ref:d1-ch4⟧ described how the means of the ccODP and of the bCCNN are obtained. This chapter shows what is computed from those means: the reserves by accident period and in total, the dispersion of the bCCNN, for which the GLM estimator of Chapter ⟦ref:d1-ch2⟧ does not exist, and three diagnostics that compare the network with the chain ladder.

## From the fitted means to the reserves {#d1-s7}

Whatever the model, the reserve is the sum of the predicted means over the future cells (Paper C, Section 3.3.3):

$$
\hat R_i = \sum_{j > n + 1 - i} \mu_{i,j}, \qquad \hat R = \sum_{i = 1}^{n} \hat R_i = \sum_{(i,j) \in \mathcal{F}} \mu_{i,j} .
$$
⟦eq:d1-eq35⟧

`reserve_by_origin(y, mu)` returns, per accident period, the latest cumulative payment $C_{i, n+1-i}$ (`latest`), $\hat R_i$ (`ibnr`), their sum (`ultimate`) and the ratio `dev_to_date` $= C_{i,n+1-i} / (C_{i,n+1-i} + \hat R_i)$; `reserve_totals()` sums them. For the ccODP, ⟦ref:d1-eq35⟧ is the chain-ladder reserve by Section ⟦ref:d1-s3.6⟧; for the bCCNN it is the sum of ⟦ref:d1-eq24⟧ over $\mathcal{F}$ at the chosen step. There are no standard errors in this strand of the code (`se` and `cv` are `NA`); companion III discusses how the uncertainty of ⟦ref:d1-eq35⟧ can be obtained.

## Dispersion of the bCCNN {#d1-s8}

A bCCNN has 547 parameters and is trained on 210 cells, so the GLM estimator ⟦ref:d1-eq18⟧, with $n_{\mathrm{obs}} - n_{\mathrm{par}}$ in the denominator, does not exist for it. Härkönen notes exactly this for her networks: "the number of parameters [...] is even larger than the number of observations which implies that the estimated overdispersion parameter cannot be computed according to Pearson statistics" (Härkönen, 2021: 53). Paper C (Section 3.3.2 and its Table 2) uses a heuristic instead: the ccODP dispersion is reduced by the relative decrease of the *validation* loss that the network achieved,

$$
\hat\phi^{\mathrm{bCCNN}} = \hat\phi_D \, \big( 1 - \max(0, \Delta_V) \big), \qquad \Delta_V = 1 - \frac{D_V(t^*)}{D_V(0)},
$$
⟦eq:d1-eq36⟧

where $D_V(t)$ is the validation deviance after $t$ steps (companion II, Section ⟦ref:d2-s7⟧). The logic is that the deviance is an estimate of $\phi$ times the degrees of freedom; if the network explains a fraction $\Delta_V$ of the out-of-sample deviance, the unexplained variance is reduced by that fraction. The cut at zero means that a network that does not beat the chain ladder on the validation cells keeps the dispersion of the chain ladder (Paper C sets 0% for its LoBs 3 and 6). The rule is `bccnn_phi(phi_odp, decrease_vali)`, and it feeds the Pearson residuals of the bCCNN.

## Diagnostics computed from the means {#d1-s9}

### Pearson residuals {#d1-s9-pearson}

The Pearson residuals (Paper C, Figure 7; `pearson_residuals()`) are computed on the true lower triangle in the script:

$$
r_{i,j} = \frac{y_{i,j} - \mu_{i,j}}{\sqrt{\hat\phi \, \mu_{i,j}}},
$$
⟦eq:d1-eq37⟧

with the model's own $\hat\phi$, namely ⟦ref:d1-eq18⟧ for the ccODP and ⟦ref:d1-eq36⟧ for the bCCNN. Under ⟦ref:d1-eq4⟧ they have mean 0 and variance 1 in the fitted cells; on the lower triangle they are out-of-sample standardised errors.

### Cumulative development factors {#d1-s9-cdf}

The cumulative development factors follow Paper C, Figure 8, and are computed by `cum_dev_factors()`. From a mean square $\mu$, the individual factor of accident period $i$ from development period $j - 1$ to $j$ and its cumulative version are

$$
\begin{aligned}
&f(i, j) = \frac{\sum_{l \le j} \mu_{i,l}}{\sum_{l \le j - 1} \mu_{i,l}}, \qquad
g(i, j) = \prod_{l = 2}^{j} f(i, l) = \frac{\sum_{l \le j} \mu_{i,l}}{\mu_{i,1}}, \\
&j = 2, \dots, n .
\end{aligned}
$$
⟦eq:d1-eq38⟧

Under the ccODP, $\mu_{i,l} = \hat a_i \hat b_l$ gives $g(i, j) = S_j / \hat b_1 = S_j$ (since $\hat\beta_1 = 0$), the same for every accident period, and by ⟦ref:d1-eq17⟧ it equals the product of the chain-ladder factors $\prod_{l=2}^{j} f_{l-1}$: every row of the ccODP factor matrix is the chain-ladder pattern. The numerical check finds the spread across rows at $3 \times 10^{-15}$. The bCCNN breaks the product form through the interaction term $\langle B, z^{(3)}(i, j) \rangle$, so its $g(i, j)$ vary with $i$: the plot of ⟦ref:d1-eq38⟧ against $j$, with one line per accident period, shows directly how far the network has let the development pattern depend on the accident period.

### Relative difference {#d1-s9-reldiff}

The relative difference (Paper C, Figure 5; `plot_relative_difference()`),

$$
\begin{aligned}
\frac{\mu^{\mathrm{bCCNN}}_{i,j}}{\hat\mu^{\mathrm{cc}}_{i,j}} - 1
&= \exp\Big\{ (w - 1)(\hat\alpha_i + \hat\beta_j) + (c - \hat c) \\
&\qquad + \langle B, z^{(3)}(i, j) \rangle \Big\} - 1,
\end{aligned}
$$
⟦eq:d1-eq39⟧

is the multiplicative correction of Section ⟦ref:d1-s4.4⟧ minus one, shown as a heat map over the whole square. It is zero everywhere at step 0.

## Summary {#d1-ch5-summary}

For every model the reserve is the sum of the fitted means over the future cells, which for the ccODP is the chain-ladder reserve and for the bCCNN the sum of the network means at the chosen step. Because the bCCNN has more parameters than cells, its dispersion cannot be estimated by the GLM formula; Paper C's heuristic reduces the ccODP dispersion by the relative decrease of the validation deviance, cut at zero. The Pearson residuals, the cumulative development factors and the relative difference to the ccODP show where and how the network departs from the chain ladder; in particular, the ccODP has the same cumulative factors for every accident period, while the bCCNN lets them vary. Chapter ⟦ref:d1-ch6⟧ locates each formula in the code and reports the numerical check.

## Summary and conclusions {#d1-ch6-summary}

The report set out the mathematics behind the bCCNN as the code implements it, and every formula was located in the code (Table ⟦ref:d1-tabnew1⟧) and confirmed by an independent numerical check (Table ⟦ref:d1-tab3⟧). Five conclusions follow.

First, the ccODP model fitted by minimising the Poisson deviance reproduces every observed row and column total of the triangle, and these marginal totals alone make its reserve the chain-ladder reserve and its development pattern the chain-ladder pattern. The dispersion does not enter the point estimates, and the unit of the payments shifts only the intercept.

Second, the bCCNN embeds the ccODP as a sub-network: the frozen embeddings hold the ccODP effects, and the skip connection carries the ccODP linear predictor to the output. The feed-forward part sees only the pair of effects of a cell, so what the network adds is a multiplicative correction of the chain-ladder means that depends on the accident-period and development-period effects jointly, that is, an interaction that lets the development pattern vary with the accident period.

Third, the loss that Keras minimises is the Poisson deviance up to a constant and the factor $2N$, so the network is fitted by the same criterion as the ccODP. At the start $\theta_0$ of Paper C's equation (14) the network reproduces the ccODP means exactly; the marginal-total equations make the gradients in the intercept and the skip weight vanish, and the zero output weights block the hidden layers, so the first step changes only the output weights of the ten random hidden features. Because the first RMSprop step is sign-like, these weights move by about $0.00316$ each whatever the size of the gradient, and the training deviance can rise for a few steps before it falls. The number of steps therefore measures how far the network is allowed to move from the chain ladder, and zero steps return the chain ladder itself.

Fourth, the reserves and diagnostics follow directly from the fitted means, but the dispersion of the bCCNN cannot be estimated by the GLM formula, because the network has more parameters than cells; the code uses Paper C's heuristic based on the decrease of the validation deviance.

Fifth, periods without payments in the fitted cells lead to effects of about $-30$, which are harmless for the chain ladder but can dominate a validation or test deviance. Neither Paper C nor Härkönen (2021) treats this case; the code masks the affected cells out of the deviance and leaves the network input unchanged. Two points therefore remain open for further work: the input of the network for such periods, and an estimator of the dispersion of the bCCNN that rests on the actual number of parameters rather than on a heuristic, which Härkönen (2021: 53) also leaves for future work. The use of these formulas in the fitting procedure is the subject of companion II, and their interpretation and evaluation that of companion III.
